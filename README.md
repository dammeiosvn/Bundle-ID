# Bundle ID

Webclip tra bundle id qua iTunes Search API.

- Tìm theo tên, dán bundle id hoặc link App Store
- Chạm thẻ để chép, giữ để mở App Store, sao để ghim
- Ghim và lịch sử lưu trên máy
- Nền `#5C5C5C`, kính mờ, bóng neumorphism

## Cài

1. Bật GitHub Pages: Settings → Pages → `main` / root.
2. Mở `https://dammeiosvn.github.io/Bundle-ID/` hoặc cài `Bundle-ID.mobileconfig`.
